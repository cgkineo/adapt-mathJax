The four suspect cases — the whole point of the exercise
S1 \(A = \lambda&nbsp;N\)×2
HTML entity &nbsp; inside the maths delimiters.
S2 \(T_{1/2}&nbsp;= 4.5 × 10^9\)
Entity &nbsp; AND a literal U+00D7 MULTIPLICATION SIGN rather than \times.
S3 \(+ \&nbsp;\beta^-\)
A backslash immediately followed by the &nbsp; entity — i.e. \ + U+00A0 once the browser decodes it. In TeX \  (backslash-space) is a control space; backslash-U+00A0 is not.
S4 \[<br />\lambda = \frac{\ln2}{T_{1/2}}<br />\]
<br /> tags INSIDE the display delimiters. The delimiters and the maths are separated by element boundaries once parsed as HTML.
